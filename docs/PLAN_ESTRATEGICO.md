# Plan Estratégico: Tarjetas Digitales Interactivas (MVP)

## 1. Objetivo del MVP
Lanzar un paquete de tarjetas digitales interactivas.

## 2. Definición del Producto
- **Tecnología:** HTML5, CSS3, JavaScript (Vanilla).
- **Formato:** Archivo `.zip` con todo el código necesario para subir a cualquier hosting o enviar por mensaje.
